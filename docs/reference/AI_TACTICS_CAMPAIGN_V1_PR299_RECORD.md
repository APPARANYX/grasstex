## Design

- **Behavior-neutral phases** (A, B, D1-D2, G) are INERT — read-only or metadata only, no combat effects
- **Behavioral phases** (C, D3-D4, E, H, I, J) are flag-gated, default OFF, flag-off identical to main
- Every new module follows the existing IIFE pattern and registers via `BattleModules.registerSystem()`
- New fields (`sim._tacticalSituation`, `battle._streetGraph`, `sq._localTask`, etc.) are owned by their respective modules
- No wire-map or state-ownership changes (all new fields are module-owned, no multi-writer fields)
